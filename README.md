# Loading the data
Data loading begins by scanning the Data folder for any files with a .xlsx extension (Excel files). Once all present files have been found, the program opens each file and reads it sheet by sheet, saving all contained information. Additionally, SampleID is extracted from the sheet name. At this stage, all duplicate peptides are still present.
Next, all loaded data are preprocessed. The first step is creating a new metadata column – PeptideKey, which concatenates peptide sequence and sequence modification information into a single column. Then, duplicate peptide entries are removed, with their unique identifiers being PeptideKey and SampleID. Moreover, modifications which low prediction confidence are removed to increase validity of detected PeptideKeys. Lastly, columns with redundant information about the data are removed to save memory. Optionally, you may choose to remove low intensity peptides, assessed either by 0.9 or 0.95 quantile of the data.
Finally, Group (usually species) column is created. It is extracted from SampleID (=Excel sheet name) column according to the following criteria:
If SampleID contains no “_“, the last character is removed.
If SampleID contains one “_“, SampleID is split by the “_“ and only the first part is kept.
If SampleID contains two or more “_“, SampleID is split by the “_“ and the first part between the first “_“ and the second “_“ is kept.
For example, „carp1“ is converted to „carp“, „chicken_e“ is converted to „chicken“ and „pep_goat_1“ is converted to „goat“.
Additionally, you may choose to merge some Groups (species) together, for example to create „cattle“ from „cow“ and „calf“.
Moreover, for higher taxonomy analyses, it is possible to create Taxonomy column, which assigns taxonomy information based on pre-defined clusters – for example, taxon „birds“ may include species „duck“, „chicken“, „goose“ and „quail“.
Preprocessed data with all newly created metadata columns are saved in CSV format to the Dataframe folder.

# Creating a reference library
The first step to finding characteristic peptides unique to each Group/Taxonomy (markers), the frequency of the peptide in every SampleID is accessed. To do that, Species/Taxonomy is split into two distinct sets – „target“ and „background“. Target is the group (either species or taxonomy cluster) that is being evaluated for markers. Background contains all the other groups currently NOT being evaluated. For both sets, every peptide is assessed on its frequency (in how many unique SampleIDs within a single Group is this peptide present?) in the dataset. This minimal „target“ frequency is specified by the user, ideally of higher nature (15 out of 15 replicates). Similarly, „background“ frequency is also specified and this time, preferably, is set low (for example 1 out of 15 unique SampleIDs in one Group) for reasons explained below. For further analysis only peptides satisfying these „target“ and „background“ frequencies are considered.
The second step is concatenation – all robust peptides (satisfying the frequency condition) are grouped together in the „target“ and the „background“ set (based on Group). Then a set subtraction is performed – all peptides present in „backround“ set are subtracted from the „target“ set, leaving only peptides unique to the „target“ Group – markers.
Higher target frequency means that a peptide is very abundant within the target group. That is beneficial for including only peptides found in all SampleIDs within that group – this means no technical noise leaks into found markers. On the other hand, low background set frequency ensures that the found markers are 100 % specific – the peptide is not found everywhere else, even as a technical noise.
All created libraries are saved in Library folder in CSV format.

# Analysing unknown samples
To analyse unknown samples, each is compared to every reference group. Similarly to reference markers, peptides are first assessed for their frequency among unknown SampleIDs (user-specified) – if sufficient, they are considered further.  Then, peptides belonging to currently analysed unknown sample are iteratively compared to peptide marker set for every reference species. For every species, a set intersection is performed, resulting in reference species markers found in currently analysed unknown sample. Based on the number of found markers, two metrics are calculated:
Confidence – portion of found markers compared to found markers from all other reference groups. For example, unknown sample X was analysed against species dog, cat and cow. For dog, there were 130 found markers, 100 for cat and 270 for cow. Then confidence was (130/500) * 100 = 26% for dog, 20% for cat and 74% for cow.
Match Score – portion of found markers compared to all available markers for select reference groups. For example, unknown sample X was analysed against species dog and cow. For dog, there were 130 found markers out of 400 present, meaning a match score of 32.5%. Similarly,  for cow there were 370 found markers out of 600 present, creating a match score of 61.7%.
If higher taxonomy clusters are used, this pipeline is first performed on higher taxonomy level. Aside from confidence and match score, taxonomy cluster with the highest confidence is highlighted to be used downstream. Species-level analysis is then performed only by comparing unknown samples to reference species within taxonomy cluster with the highest confidence. This additional step significantly improves species-level confidence of the analysis.
To demonstrate, let‘s use taxon carnivores consisting of dog and cat. Unknown sample X has the highest confidence in the carnivores taxon, so species-level analysis is performed only against dog and cat marker sets. Confidence here is improved due to denominator being smaller, (dog[100] + cat[200]) versus (dog[100] + cat[200] + other species[300]) if the species-level analysis was not limited to carnivores.
